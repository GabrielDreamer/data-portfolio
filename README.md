# data-portfolio - Gabriel Lima

Hi, I'm Gabriel — a Computer Science graduate with professional experience in IT support, infrastructure, and Microsoft 365 environments. Over time, I discovered my passion for data analysis: transforming raw information into insights that drive decisions.  

This repository is my personal space to showcase projects where I apply Python, SQL, Power BI, and Excel to real-world inspired scenarios.

## 🎯 Purpose
To build a portfolio that showcases my ability to:
- Clean and analyze data in different formats.
- Create interactive dashboards and automated reports.
- Apply basic machine learning techniques to generate insights.
- Document results clearly in both Portuguese and English.

## 📂 Projects
- [Project 1: Sales Dashboard](projeto1-vendas/README.md)  
  Analysis of fictitious e-commerce data, including revenue metrics, average ticket size, and best-selling products.

- [Project 2: Security Log Analysis](projeto2-logs-seguranca/README.md)  
  Identification of unauthorized access attempts in firewall logs using Python and Pandas.

- [Project 3: Customer Churn Prediction](projeto3-churn/README.md)  
  Machine learning model to predict customer cancellations, with accuracy metrics and insights.

## 🛠️ Tools and Technologies
- Python (Pandas, NumPy, Matplotlib, Scikit-learn)
- SQL
- Power BI / Excel
